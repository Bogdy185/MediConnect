# 🏥 MediConnect — Ghid & Quiz de Orientare Medicală

MediConnect este o aplicație web interactivă concepută pentru a ajuta utilizatorii să înțeleagă specializările medicale și să aleagă medicul potrivit pentru simptomele lor.

## 🎯 Cui se adresează și cum funcționează
Aplicația este destinată colegilor și elevilor care doresc să-și testeze cunoștințele de educație pentru sănătate. 
* Apeși butonul **START QUIZ**;
* Citești fiecare întrebare legată de simptome (cardiologie, stomatologie, dermatologie, ortopedie);
* Selectezi varianta corectă și primești feedback imediat cu acumulare de puncte până la scorul final.

## 🌐 Acces online
Aplicația poate fi testată live aici: [MediConnect pe GitHub Pages](https://[username].github.io/mediconnect/)

## 🛠️ Tehnologii folosite
* **HTML5:** Structura semantică a paginii și a zonelor de conținut;
* **CSS3:** Paletă cromatică medicală (albastru `#0056b3`, verde mentă `#20c997`), fonturi Google (Montserrat, Open Sans) și design responsive;
* **JavaScript (Vanilla):** Logica dinamică a quiz-ului, validarea răspunsurilor și calculul scorului în timp real.

## 🤖 Cum a fost folosit AI-ul în proiect
* Verificarea corectitudinii structurii HTML și respectarea accesibilității;
* Depanarea (debugging) problemei de click multiplu la întrebări;
* Asistență în redactarea documentației și a pașilor din fișele de lucru.
